# Security Policy

## Reporting a security concern

Do not report security vulnerabilities, account problems, exposed credentials, or privacy-sensitive information through public GitHub Issues.

Use the official KickOff Manager Support page:

https://kickoff-manager-dfdea.web.app/html/support.html

Include:

- A clear description of the concern
- The affected page or workflow
- Reproduction steps that do not expose real credentials or personal information
- The browser and device used
- The potential impact

## Sensitive information

Never submit:

- Passwords or recovery codes
- Firebase, GitHub, or Google access tokens
- Service-account files
- Private email addresses
- Authentication session information
- Sensitive tournament or participant data

## Scope

This repository is the public feedback hub. It intentionally contains no KickOff Manager application source code.
