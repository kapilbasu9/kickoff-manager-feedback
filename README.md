# ⚽ KickOff Manager Feedback

Welcome to the official public feedback hub for **KickOff Manager**, a browser-based football and eFootball tournament-management platform.

## Live application

**Use KickOff Manager:**  
https://kickoff-manager-dfdea.web.app

## What this repository is for

Use this repository to:

- Report reproducible application bugs
- Suggest improvements and new tournament features
- Share usability and mobile-layout feedback
- Request documentation clarification
- Track publicly acknowledged issues

This repository intentionally contains **no KickOff Manager application source code**.

## Before reporting a bug

Please:

1. Confirm the problem occurs on the live application.
2. Refresh the page and try again.
3. Check existing issues for the same problem.
4. Remove personal, account, tournament-owner, or sensitive tournament information from screenshots.
5. Use the bug-report template and provide clear reproduction steps.

## Feature suggestions

Feature requests are welcome. Explain:

- The problem you want to solve
- The proposed behaviour
- Who would benefit
- Any alternatives you considered

## Private support and security

For account, privacy, or security-sensitive matters, **do not create a public issue**.

Use the official Support page:

https://kickoff-manager-dfdea.web.app/html/support.html

Never post passwords, recovery codes, Firebase credentials, access tokens, private email addresses, or sensitive tournament information in GitHub Issues.

## Public beta

KickOff Manager is currently in public beta. Features and interface details may change as testing and feedback continue.
